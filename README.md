# 💌 Surprise anniversaire — Bubu

Petite expérience romantique en HTML/CSS/JavaScript vanilla.

## Structure

```text
.
├── index.html
├── style.css
├── script.js
├── README.md
└── .gitignore
```

## Lancer en local

Aucune dépendance n'est nécessaire.

Tu peux simplement ouvrir `index.html` dans un navigateur.

Pour un serveur local :

```bash
python -m http.server 8000
```

Puis ouvre `http://localhost:8000`.

## Séquence

1. Écran d'accueil + enveloppe interactive.
2. Ouverture de l'enveloppe et effets lumineux.
3. Apparition du personnage chibi.
4. Message d'anniversaire.
5. Déploiement de la lettre.
6. Écriture progressive de la lettre.
7. Finale avec cœurs flottants.
8. Bouton « Rejouer la surprise ».

Le projet n'utilise aucune dépendance externe ni image externe.
